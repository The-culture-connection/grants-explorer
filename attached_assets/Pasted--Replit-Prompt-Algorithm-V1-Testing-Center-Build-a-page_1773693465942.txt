## Matching logic for V1

Implement a rules-based weighted scoring algorithm.

### Step 1. Active source filter

Before matching, filter all opportunities so that only these sources remain:

* simpler_grants
  n- grants_gov
* sam_gov_opportunities
* sbir
* 360giving
* california_grants_portal
* world_bank_procurement
* ted_eu

If source names are stored differently, create a source normalization map.

### Step 2. Eligibility gate

If the organization clearly does not meet basic eligibility, the score should be 0 and the opportunity should be excluded from top matches.

Examples:

* nonprofit-only grants exclude small businesses
* small business opportunities exclude nonprofits
* geography restrictions should be respected when explicit

Create a helper like:

* passesEligibility(org, opp)

### Step 3. Weighted scoring

Use this V1 score model:

* mission/topic fit: 35 points
* eligibility fit: 25 points
* geography fit: 15 points
* funding size fit: 15 points
* organization maturity fit: 10 points

Final score should total 0–100.

### Step 4. Explainability

Every match result must include:

* reasons: array of positive fit explanations
* risks: array of caution notes

Examples of reasons:

* Eligible nonprofit applicant type
* Strong topic overlap in maternal health and community education
* Geographic fit for U.S.-based applicants
* Award size appears realistic for the organization’s scale

Examples of risks:

* Opportunity appears highly competitive
* Funding size may exceed current organization capacity
* Opportunity may require prior federal grant management experience
