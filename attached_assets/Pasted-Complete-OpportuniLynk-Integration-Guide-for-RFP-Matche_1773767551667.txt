Allowed Event Types
Event Description Priority
user.created New user signup High
document.uploaded Document uploaded for analysis Medium
opportunity.viewed User views an opportunity Medium
opportunity.analyzed Analysis/scoring completed High
opportunity.saved User saves opportunity High
opportunity.applied User applies to opportunity High
opportunity.outcome Win/loss outcome recorded Critical
Payload Format
{
"event_type": "opportunity.outcome",
"source_user_id": "firebase-uid-or-email",
"timestamp": "2026-02-05T14:30:00Z",
"data": {
"opportunity_id": "opp_12345",
"outcome": "won",
"revenue_value": 75000,
"close_date": "2026-02-05",
"notes": "Optional context"
}
}
2
Required Fields:
 event_type — Must match one of the allowed events above
 source_user_id — Your system's user identifier (for mapping)
 data — Event-specific payload object
Response Codes
Code Meaning
200 Success — data staged for processing
400 Invalid payload or unsupported event type
401 Invalid or missing signature
404 Product not found or inactive
503 Kill switch active — integration suspended

Data Flow
1. Webhook received → signature verified
2. Data staged in quarantine (pending status)
3. OpportuniLynk admin reviews & approves
4. Approved data imported to core intelligence
